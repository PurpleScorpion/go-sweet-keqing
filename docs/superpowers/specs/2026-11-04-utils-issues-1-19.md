# 工具函数缺陷修复计划

## 范围与兼容约束

基准为 main / 3fcec45b223cdddff78673d8f6972538891ea6c1。依次修复 GitHub #1–#19，只使用分支 fix/utils-issues-1-19，最后推送并创建一个 PR，不自动合并。

项目没有独立正式设计文档；现有契约依据为 README.md 各工具章节、keqing 下公开函数注释，以及对应 Issue 的固定版本源码和复现。README 与实现不一致部分以当前公开签名保持源码兼容，在 #19 修正文档。

- 保留现有函数名称、参数和返回值；需要可恢复错误的能力通过新增接口提供。
- 金额以整数分为边界，十进制输入精确解析；超过分的余数向零截断，乘除也遵循此规则。无效数值、非有限数与溢出明确失败，沿用现有金额接口的 panic 形式。
- List/Set 的 hash 仅作为候选索引，最终相等以 Equal(T)（若实现）或 Go == 为准。自定义 hash 必须对相等值给出相同结果；集合中的键属性不得在外部变更。
- Iterator 提供快照；集合运算从锁内复制的快照计算，避免递归获取读锁。
- RandomId 保留现有入口；多实例唯一性通过显式唯一 workerID 的配置契约保障。初始化、配置与生成需并发安全，生成失败不能作为正常 0 返回。
- 日历“天”按当地日历日期计算，日期范围统一返回包含的末纳秒；超出可表示范围明确拒绝。
- CopyFile 不得截断同一源文件；RSA 写入失败不得伪报成功，限制私钥权限，失败加载不得污染现有密钥对。
